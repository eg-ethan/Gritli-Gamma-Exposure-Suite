## Hidden assumptions & gotchas

- **Never run `load-closes` (or anything touching the DB) while `serve` holds
  it** — SQLite is single-owner by design; load closes first, then serve.
- **CRLF noise:** `gofmt -w` over whole directories flips working-tree line
  endings; git then shows `M` with EMPTY diffs (autocrlf). Check with
  `git diff` before "reverting" anything; content-identical files drop out
  on commit.
- **Git Bash `/tmp` ≠ Windows %TEMP%** for exe arguments — pass repo-local
  or `C:/…` paths to built binaries.
- **Python heredocs mangle `\\n`** into real newlines inside inserted code —
  after any `python - << 'EOF'` code patch, build immediately; fix rune
  literals with the Edit tool.
- **Go struct literals can't start an `if` condition** (`if Leg{…}.Label()`
  parses as a block) — assign to a variable first.
- **IBKR `IsConnected()` is a method**, not a property (C#).
- **Python `round` is banker's rounding** — the hedge goldens ban it; Go
  `math.Round` is half-away-from-zero and `TargetHedgeShares` pins that.
- **`time/tzdata` is imported in `cmd/gexctl`** — `USSession`'s
  America/New_York lookup silently degrades (gate never arms) without it on
  Windows/static Linux. Don't remove that blank import.
- **Staleness gate arms only 09:30–16:00 ET** — tests/smokes run outside
  those hours will show `ok` on frozen spots BY DESIGN; the gate itself is
  covered by `TestHedgeStateMachine` with an injected mid-session clock.
- **The Go sim ignores pause/resume** (readLoop handles sub_set/error/
  spot_ack only) — only the C# edge tears down on pause. See open item 2.
- **Benchmark subscription is edge-flag-driven**: a GUI pair change to a NEW
  benchmark does not reach a running edge — restart it with the new
  `--hedge-bench` (documented trade-off; the core tolerates any registered
  spot-only ticker). The `--edge-sim` path reads the CURRENT stored pair at
  sim start (`svc.Hedge()`).
- **Hedge asset must be a watchlist ticker** (solver Greeks need the chain);
  `SetHedgePair` enforces it, `no_asset_feed` state explains boot drift.
- **`omitempty` was removed** from `HedgeState.NetDelta/DollarDelta/
  HedgeValue/TargetShares` — a zero target is meaningful and must render.
